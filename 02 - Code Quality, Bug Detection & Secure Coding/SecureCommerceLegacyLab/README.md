# SecureCommerceLegacyLab

Training-only .NET 8 sample intentionally containing bugs, code-quality problems and security vulnerabilities.

Scenario: B2B commerce platform with authentication, product search, ordering, discounting,
inventory, payments, file upload, admin reporting and audit logging.

Use it with VS Code + Claude for:
- Code quality review
- Bug detection
- Secure coding
- Refactoring
- Testing
- Validation of AI-generated changes

DO NOT use this code in production.
